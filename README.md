# hbRails Releases

Canal público oficial de distribuição do **hbRails**.

Este repositório será usado para publicar releases binárias, instaladores,
checksums e metadados públicos necessários ao consumo e à validação do hbRails.

## Status

A infraestrutura pública está em preparação. Ainda não há release pública
disponível para instalação.

## Distribuição

Quando o fluxo de release estiver implementado, os pacotes oficiais serão
publicados na seção **Releases** deste repositório.

Os artefatos públicos deverão identificar, conforme aplicável:

- produto e versão;
- plataforma/target;
- build/release id;
- checksums/digests;
- metadados de compatibilidade e proveniência técnica necessários à validação.

O canal público não depende da exposição da infraestrutura privada de
desenvolvimento do projeto.

# hbRails Releases

Official public distribution channel for **hbRails**.

This repository will be used to publish binary releases, installers, checksums,
and public metadata required to consume and validate hbRails.

## Status

The public distribution infrastructure is being prepared. No public release is
currently available for installation.

## Distribution

Once the release workflow is implemented, official packages will be published
in this repository's **Releases** section.

Public artifacts should identify, as applicable:

- product and version;
- platform/target;
- build/release id;
- checksums/digests;
- compatibility and technical provenance metadata required for validation.

The public channel does not depend on exposing the project's private development
infrastructure.
